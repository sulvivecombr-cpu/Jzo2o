家政服务 O2O 平台 — Spring Cloud Alibaba 微服务后端

此仓库只包含后端微服务（PC 运营端 / 机构端、APP、小程序前端不在此仓库中）。 下方每个服务都通过 /<context-path>/doc.html 暴露 Knife4j 接口文档， 可以直接在此页面浏览、调试真实接口。
